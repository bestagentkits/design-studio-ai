# Claude Design interaction study

Observed directly through the authorized Windows Computer Use plugin on 2026-09-08. A new fictional Forma ceramics landing-page project was created for this study; existing user projects were not opened or edited. No project was published.

## Verified interactions

- Home begins with a large prompt composer, optional design system, model choice and visual deliverable templates.
- Sending a short prompt opens one workspace: conversation on the left, interactive questions in the main viewport. Contextual questions covered audience, main conversion action, tone and content sections.
- A follow-up question surface included palette previews, typography choices and photo-led versus type-led direction. It offered decide-for-me, further questions and send-answer controls. Selected palette/type answers appeared as a compact conversation receipt.
- The generated artifact appeared in the main viewport with the conversation retained. The test produced a ceramics page with clearly labeled image placeholders.
- Edit mode offers Simple, Pro, Code and Tweaks tabs. Selecting a heading reveals text, typography, color, sizing, spacing and appearance controls. Pro includes a layer hierarchy and more layout controls; Simple removes that extra hierarchy.
- The AI-created Tweaks panel exposes named accent choices and a Photo/Type hero switch. Changing to Type immediately changed the hero layout; changing accent to sage updated page accents. These changes were saved in the study project.
- Present and Share controls exist. They were not used to publish this study.

## Product implications

Implement contextual interview questions inside the workspace, a durable answer receipt, editable scope and explicit scope approval. Keep missing answers distinct from permission to proceed. The study briefly displayed empty-answer responses while its form remained visible; this is an observed interaction symptom, not a diagnosis of Claude's internals.

Expose common design changes at a semantic level (theme/layout choices) and keep detailed node editing available. Agent tools should share the same brief and document revisions as the interface. Add actionable design preflight findings with exact layer IDs; visual preview still determines aesthetic quality.

This study establishes observed onboarding/editor behavior only. It does not establish feature parity with Claude Design, Three.js Editor or After Effects, nor validate every control in those products.
